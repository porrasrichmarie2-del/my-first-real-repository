Program Description
This is a simple Python Grade Calculator. It calculates the average of three grades and shows whether the student passed or failed.

How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run: python main.py
5. Enter your name and three grades.
